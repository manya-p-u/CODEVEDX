# CODEVEDX - Machine Learning Internship Projects

Welcome to my CODEVEDX Internship repository.

This repository contains all the Machine Learning projects completed as part of my CODEVEDX Internship Program. Each project demonstrates different Machine Learning techniques, including data preprocessing, exploratory data analysis (EDA), model building, evaluation, and prediction using real-world datasets.

## Projects

### Task 1: Titanic Survival Prediction
- Predict passenger survival using machine learning classification models.
- Concepts: Data Cleaning, EDA, Feature Engineering, Classification.

### Task 2: Movie Rating Prediction
- Predict movie ratings using historical movie data.
- Concepts: Regression, Feature Engineering, Data Analysis.

### Task 3: Iris Flower Classification
- Classify Iris flowers into Setosa, Versicolor, and Virginica species.
- Concepts: Classification, Data Visualization, Model Comparison.

### Task 4: Sales Prediction
- Predict product sales based on advertising expenditure and marketing data.
- Concepts: Regression, Business Analytics, Sales Forecasting.

### Task 5: Credit Card Fraud Detection
- Detect fraudulent credit card transactions using machine learning.
- Concepts: Classification, Class Imbalance Handling, SMOTE, Model Evaluation.
